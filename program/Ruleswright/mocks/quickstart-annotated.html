Quickstart, annotated

The same three steps as the quickstart, with the requirement each line satisfies pinned beside it. This is the reviewer's page: the docs bar (runnable, expected output, zero I/O) is not a vibe — it is clause by clause, and CI's doc-example test runs this exact script.

01

Generate a campaign

quickstart.ts — annotated
const pack = await generateCampaign({
  theme: "dark-fantasy",     // FR-21 · one of two sample themes
  seed: 42,                   // FR-17 · same seed ⇒ byte-identical pack
  knobs: { threat: "high" },  // FR-18 · theme-declared, machine-readable
});
// NFR-perf: full pack in < 2 s · fully offline · no network calls

What the doc must show: the pack summary line — schemaVersion · artifact count · validation time — because the compiler dogfooding the runtime validator (FR-2) is itself a selling point.

02

Build a character

quickstart.ts — annotated
const rt = new Runtime(pack);
// FR-2 · load validates schema + semantics; throws ErrorCard[]

const brynn = rt.createCharacter({
  name: "Brynn",              // FR-5 · plain serializable state
  race: "hillfolk",           // FR-6 · race/class matrix is pack data
  classes: [{ id: "warden", level: 1 }],  // FR-6 · direct level-set
});

What the doc must show: derived stats with their provenance — hp 10 (1d8+2 · pack formula) — because "rules are data" is the product's one-sentence pitch, and this line is where the reader first sees the engine reporting the pack's conventions as its own (FR-3).

03

Run three rounds

quickstart.ts — annotated
const fight = rt.startCombat(
  { allies: [brynn], enemies: [rt.spawnMonster("barrow-wight")] },
  { rng: mulberry32(42) }        // FR-1 · injectable, seeded
);

for (let round = 1; round <= 3; round++) {
  while (!fight.roundComplete) fight.step();
  // FR-10 · begin → declare → resolve → end, host-paced
  console.log(fight.events.sinceRound(round));
  // FR-13 · every event carries why (rule id + roll refs)
}

What the doc must show: three event lines with their why tails. The event stream is the demo — a host that sees provenance in the quickstart understands the whole runtime model in one screen (FR-13).

The bar, stated as checks

✓

Every line is copy-paste runnable — no /* ... */, no "imagine a party here." The doc-example CI test runs the quickstart verbatim.

✓

Every step prints its expected output — the reader verifies success without trusting the prose (NFR-DX).

✓

Zero I/O in the whole script — no files, no network, no storage. serialize() appears only as a mention, because persistence is the host's job (FR-14).

✓

Three rounds end with byte-identical state across Node, browser, and Electron — the determinism guarantee demonstrated, not claimed (NFR-Determinism).
