API map — the whole library on one page

Every signature here is illustrative — Architect owns the real ones. What this page fixes is coverage: each requirement appears at least once in a callable shape, and the whole public area fits on one page. If the final API can't fit a page, it is too big.

compiler

generateCampaign({ theme, seed, knobs? })     → Pack          // FR-17 · < 2 s · offline
listThemeKnobs(theme)                          → KnobDecl[]    // FR-18 · machine-readable

runtime — lifecycle

new Runtime(pack)                              // validates at load (FR-2) · throws ErrorCard[]
rt.createCharacter({ name, race, classes })    → Character     // FR-5 · direct level-set
rt.awardXp(char, amount)                        → Event[]       // FR-6 · host awards
rt.spawnMonster(id)                             → Combatant     // FR-16 · same machinery
rt.assembleEncounter({ budget, party, seed })   → Encounter     // FR-16 · deterministic
rt.startCombat({ allies, enemies }, opts?)      → Combat        // opts.rng injectable (FR-1)

character

char.derived()                                  → hp · ac · attackBonus · saveTargets   // FR-3
char.knownSpells / char.slots / char.pools      // FR-8 · FR-9 · plain JSON
char.applyTheme(id) / char.removeTheme(id)      // conditions (FR-7)
char.prepare(spellId, slotRef)                  // memorize — a pack action (FR-9)
char.serialize() / Character.deserialize(json)  // FR-14 · serializer 1 of 3

combat — stepwise

fight.step()                                    // begin → declare → resolve → end (FR-10)
fight.roundComplete                             // host paces the loop
fight.declare(actionId, targetRef)              // validity checked against pack (FR-4)
fight.respond(triggerId, choice)                // answer an offered trigger (FR-4, FR-13)
fight.on(fn) / fight.off(fn)                    // subscribe — never required (FR-13)
fight.events.sinceRound(n)                      // the provenance stream
fight.serialize() / Combat.deserialize(snap, pack)  // FR-14 · serializer 3 of 3 · rng included

tables — one engine (FR-15)

rt.rollTable("tables.district-scavenge", rng?)  → RollResult · weighted / ranged / nested

the error surface

ErrorCard { severity · artifactId · jsonPath · rule · message · hint? }

One error shape everywhere — load validation, illegal builds, snapshot refusal (FR-2, FR-5, FR-14). The validation-errors surface is its gallery.
