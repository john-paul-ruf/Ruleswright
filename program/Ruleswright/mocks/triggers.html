Triggered actions — reactions as data

Packs declare actions that ride the event substrate: when event X occurs, actor Y may react. The engine supplies the hook mechanism and nothing else — it has never heard of "parry" (FR-4, FR-13).

Anatomy

pack actions — one reactive action, one reactive feat
"parry": {
  "trigger": "on:event(attack:rolled, target=self)",
  "cost": { "slots": { "reaction": 1 } },
  "effect": { "opposed": "grace vs attacker.grace",
             "onWin": "negate(attack)" }
}

// a feat can be reactive too — same substrate
"second-wind": {
  "trigger": "on:event(condition:applied, target=self)",
  "once": "per:encounter",       // gating is pack data
  "effect": { "heal": "1d6 + vigor" }
}

The engine offers a trigger as an event; the host answers in its own pacing — prompt a player, let the AI answer, decline. Stepwise by construction (FR-10).
