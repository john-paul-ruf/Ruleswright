The generation pipeline

generateCampaign({ theme, seed, knobs }) is one call, but underneath it is a chain of named stages behind a stable interface (Extension Commitment 3). A future narrative stage slots in without touching existing stages — that is the v2 seam, built into v1.

Named stages, stable interface

1 · stats

abilities, named saves

→
2 · skills

theme-flavored skill list

→
3 · feats

incl. one reactive (FR-12)

→
4 · classes

progression tables, 1–10

→
5 · magic

spells, pools, slots

→
6 · bestiary

statblocks, threats

→
7 · tables

encounters, loot, flavor

→
8 · validate

the runtime's own validator (FR-2) — dogfooded

Each stage reads the theme template, the knobs, and the seeded RNG; each contributes its section of the pack. Stages are registered, ordered, and replaceable — generation is a pipeline, not a monolith.

Two sample themes, two showcases

Both themes exercise every capability at least once (the FR-21 coverage floor); each leans into a different proof (FR-21).

dark-fantasy

vancian showcase

  • ~3 classes with attack tables & HD
  • ~40 spells, levels 1–3 — all coined names (Q8)
  • full race matrix, demihuman multi-class, level caps
  • five named saves · melee + ranged + one burst spell

zombie-urban

drain-pool & table showcase

  • survivor classes, stamina pool — no vancian
  • skills-heavy: scavenging, fortification, streetwise
  • table-heavy: infection saves, district loot
  • same coverage floor — proves the engine needs neither slots nor spells
output

  // fully offline; no network calls; < 2 s per pack (NFR-Performance)

Determinism is the contract

✓

Same theme + seed + knobs ⇒ byte-identical pack (FR-17). This is what makes GM hand-edits anchorable across regenerations (FR-19) — the theme-knobs surface shows the loop.

◈

Knob values feed generation and are recorded in the pack's provenance (FR-18) — the manifest tells you why the pack came out the way it did.

▲

The compiler emits only packs the runtime validator accepts. There is no separate "generator QA" — dogfooding is the QA (FR-2, FR-17).
