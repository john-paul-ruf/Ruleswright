Theme knobs & composition

Two promises, one page. First: a host renders a settings form from theme data alone — it never knows the theme (FR-18). Second: a new theme is JSON with patches, not code (FR-20). And regeneration is byte-identical, so GM edits anchor forever (FR-17, FR-19).

Knobs are machine-readable declarations

theme.json — knobs block
"knobs": [
  { "id": "threat",       "type": "enum",   "values": ["low","medium","high"], "default": "medium", "desc": "Bestiary threat budget" },
  { "id": "techLevel",   "type": "enum",   "values": ["medieval","scavenged"], "default": "medieval", "desc": "Equipment flavor" },
  { "id": "spellDensity", "type": "range",  "min": 1, "max": 5, "default": 3, "desc": "Spells per level, L1–3" },
  { "id": "grittiness",   "type": "enum",   "values": ["heroic","mortal"], "default": "heroic", "desc": "HP and damage scaling" }
]

The host reads that block and renders this form — without a single theme-specific line of code (controls shown in host-neutral styling; the theme only supplies the data):

Themes compose

A theme may declare a base plus patches; merge semantics are documented and deterministic. The shipped sample themes stand alone — but composition is exercised by tests, because that seam is how content scales (FR-20).

winter-march.json — a derived theme
{
  "id": "winter-march",
  "base": "dark-fantasy",
  "patches": [
    { "op": "add",    "path": "/content/conditions/frostbitten",
      "value": { "duration": 5, "stacking": "refresh" } },
    { "op": "remove", "path": "/content/monsters/barrow-wight" },
    { "op": "merge",  "path": "/knobs", "value": { "coldSeverity": { "type": "range", "min": 1, "max": 3, "default": 2 } } }
  ]
}

Same patch vocabulary as the GM override layer (FR-19) — one merge model, learned once.

✓

Determinism (FR-17): same theme + seed + knobs ⇒ byte-identical pack. That is what makes hand-edits to generated content anchorable — regenerate, re-apply, nothing drifts.

◈

Pipeline seam (Extension Commitment 3): generation is a chain of named stages — skills → feats → bestiary → tables → flavor. A future narrative stage slots in without touching existing stages.
