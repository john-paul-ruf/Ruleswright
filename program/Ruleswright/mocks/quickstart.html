Quickstart

The NFR-DX contract made visible: every line below is copy-paste runnable, and every step shows its expected output. If a shipped doc example can't do this, the docs are broken.

01

Generate a campaign

One call: theme, seed, knobs. Out comes a complete, validated content pack — every rule, skill, feat, class, save, spell, table, and monster.

quickstart.ts 
import { generateCampaign } from "ruleswright/compiler";

// Theme + seed + knobs → complete pack. Fully offline.
const pack = await generateCampaign({
  theme: "dark-fantasy",
  seed: 42,
});
output
✓ dark-fantasy · schemaVersion 1 · 1,204 artifacts · generated in 1.3 s
✓ validated by the runtime's own validator in 214 ms
  2 classes · 41 spells (levels 1–3) · 5 named saves · 18 bestiary entries
02

Build a character

The pack was validated at load; the runtime reads progression from its tables. Derived stats come from pack formulas — note the engine reporting the pack's convention, not its own.

quickstart.ts — continued 
import { Runtime } from "ruleswright/runtime";

const rt = new Runtime(pack);

const brynn = rt.createCharacter({
  name: "Brynn",
  race: "hillfolk",
  classes: [{ id: "warden", level: 1 }],
});
output
brynn.derived()
→ hp 10 (1d8+2 · pack formula) · ac 15 (descending · pack convention)
  saves: vigor +2 · grace +1 · tenacity +0 · reason −1 · presence +0
03

Run three rounds

Combat advances stepwise, so your UI can animate or prompt between steps. Every mutation emits an event carrying its provenance — why it happened.

quickstart.ts — continued 
const fight = rt.startCombat({
  allies: [brynn],
  enemies: [rt.spawnMonster("barrow-wight")],
});

for (let round = 1; round <= 3; round++) {
  while (!fight.roundComplete) fight.step(); // begin → declare → resolve → end
  console.log(fight.events.sinceRound(round));
}
output
[r1] roll:attack  d20[14]+3=17 ≥ ac 15 → hit   why: barrow-wight.claw@bestiary[12]
[r1] damage:apply 6 slashing · brynn.hp 10→4   why: d6[4]+2 · claw.onHit
[r2] condition:apply shaken (1 round)          why: wight.frightful-presence
✓

Same theme + seed + knobs ⇒ byte-identical pack. Same inputs ⇒ identical rolls — on Node, in browsers, in Electron. (FR-1, FR-17)

◈

The engine performed no I/O anywhere above. serialize() hands you JSON; your app owns storage. (FR-14)
