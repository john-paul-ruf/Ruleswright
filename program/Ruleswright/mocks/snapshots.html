Snapshots & persistence

Lossless, plain-JSON snapshots the host stores wherever it likes. The engine performs no I/O of any kind — no filesystem, no DB, no localStorage, no autosave timers. serialize() returns a string; storage adapters are third-party territory (FR-14).

Three independent serializers

character.serialize()
{
  "id": "brynn",
  "abilities": { /* … */ },
  "classes": [ { "id": "warden",
    "level": 3, "xp": 2400 },
    { "id": "hexer", "level": 2 } ],
  "pools": { "stamina": { /* … */ } },
  "slots": { /* bindings */ },
  "conditions": ["sapped"],
  "inventory": [ /* … */ ]
}
party.serialize()
{
  "id": "party-1",
  "members": ["brynn", "sela"],
  "shared": { "rations": 4 }
}
// membership + shared state;
// characters serialize separately
combat.serialize()
{
  "pairsWith": "party-1",
  "round": 2, "turn": 3,
  "order": ["wight","brynn"],
  "combatants": { /* transients */ },
  "rng": { "state": "0x9f3a…" },
  "pack": { "id": "dark-fantasy",
    "schemaVersion": 1,
    "contentHash": "e41c…" }
}

A combat snapshot names the party snapshot it pairs with — the pairing is stated in the docs (FR-14), and the pack identity rides inside every snapshot.

Resume means the next roll matches

output — the FR-14 test, stated plainly
uninterrupted:  d20[7] · claw hits · 6 slashing
serialized at round 2, turn 3, mid-turn
resumed:        d20[7] · claw hits · 6 slashing   ✓ identical

RNG state is part of the payload (FR-1) — that is the whole trick, and it is testable, not aspirational.

Load refuses loudly on mismatch

REFUSED snapshot.load rule: E-SNAP-01

Pack hash e41c… expected, 9a02… loaded — refusing rather than producing mangled characters.

▲

No v1 migration, by contract: a schema or content version bump renders old snapshots stale, and the API says so plainly — the error names the versioning discipline (FR-23) rather than guessing.

The boundary is the point

✓ The engine: computes, validates, serializes. Pure functions over pure data.

— The host: files, databases, localStorage, autosave, cloud sync, undo stacks — all third-party territory, all shapes supported because the payload is plain JSON.
