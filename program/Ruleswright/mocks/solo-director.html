01 · Advance a bounded slice

import { advanceSolo, readNarration } from 'ruleswright/runtime';
import type { Adventure } from 'ruleswright/runtime';

export function soloSlice(adventure: Adventure) {
  const result = advanceSolo(adventure, { maxSteps: 32 });
  const messages = readNarration(adventure);
  // Host renders facts/text and returns control according to result.reason.
  return { result, messages, snapshot: adventure.serialize() };
}
// SoloResult: { reason, stepsUsed, events, view }
// awaiting-player | awaiting-choice | completed | defeated | abandoned |
// budget-exhausted | stalled
// Each actual transition consumes one step; no-progress is never victory.

02 · Yield without taking the player’s choice

Director

Handles legal enemy actions, movement and reactions. Stable policy priorities and tie order; optional tie entropy uses its own saved stream. Passes when unable to act.

Player

Owns character turns, reactions, routes, reward recipients and preparation. Pending player offers survive save/reopen. A smaller step budget changes pacing, not the chosen actions.

03 · Read → render → acknowledge

const messages = readNarration(adventure); // pure, no RNG or cursor change
// Message: { messageId, sequence, templateId, event, text }
// event keeps {type, at, actor?, target?, payload, why:{rule,rolls}}.
// why.rolls are the existing display strings, not invented numeric roll fields.
const throughSequence = messages[messages.length - 1]?.sequence;
if (throughSequence !== undefined) {
  const v = adventure.view();
  adventure.dispatch({ type: 'ack-narration', adventureId: v.adventureId,
    expectedRevision: v.revision, throughSequence });
}
// Acknowledge only after the host has presented messages.
// Save after acknowledgement; reopened reads start after the saved cursor.

Negative damage amounts render as healing. Missing templates retain the source event as a factual fallback. Names resolve from stable saved bindings; a prose fragment cannot grant loot, finish a fight or alter a rule.

Paused movement and restart

New pendingMove records each offered {from,to,reactorId} tuple. Resume waits for the offer queue, suppresses that exact departure, and checks a different edge or threatener. Legacy saves without the records retain legacy first-step suppression. No hidden private-only correction.

Acknowledgement beyond the journal or behind the saved cursor refuses. Budget exhaustion and stalemate yield explicitly. Pure reads never acknowledge messages.
