A finite adventure, driven by your host.

Approved contract for implementation. New play APIs are not implemented by this Author change. Architect fixes signatures; DB schemas fix portable data. Examples below are the downstream runnable-doc target.

The compiler creates a pack-bound document. The runtime consumes that document without importing the compiler. Routes, objective, encounters and rewards are explicit authored data.

01 · Generate → open → choose

import { generateAdventure } from 'ruleswright/compiler';
import { createAdventure, restoreAdventure } from 'ruleswright/runtime';
import type { Pack, AdventureTemplate, AdventureStartOptions } from 'ruleswright/schema';

export function adventureExample(pack: Pack, template: AdventureTemplate,
  options: AdventureStartOptions) {
  // template must match this effective pack. A bundled recipe can be bound
  // explicitly with loadAdventureTemplate(templateId, pack) from the compiler.
  const definition = generateAdventure({ pack, template, seed: 42 });
  const adventure = createAdventure(pack, definition, options);
  const before = adventure.view();
  // Host presents before.choices and obtains an explicit player selection.
  const choose = (choiceId: string) => adventure.dispatch({
    type: 'choose', adventureId: adventure.view().adventureId,
    expectedRevision: adventure.view().revision,
    nodeId: adventure.view().nodeId, choiceId
  });
  const bytes = JSON.stringify(adventure.serialize());
  const reopened = restoreAdventure(pack, definition, JSON.parse(bytes));
  return { definition, before, choose, reopened };
}

Earned, pending, claimed

A successful encounter resolves the node, stages its roll once, then exposes a claim. XP is explicitly per eligible member; class splitting stays with awardXp. Claim updates XP, inventory and receipt together. No reroll on retry.

Rest means rest

Node policy controls rest and preparation. Rest refills pools and clears bindings; it does not heal HP or resurrect. Preparing, equipping and consuming items are explicit commands. Travel does not tick round conditions.

Unavailable is not completed. Defeat and abandon cannot grant success rewards. A wrong node, choice, recipient, definition hash or revision refuses before any mutation.

04 · Resume from one document

Host persists pack + immutable definition + one adventure snapshot. The snapshot includes the active encounter, party, reward records, separate streams and journal/cursors. Save all of it atomically. There is no database, timer or cloud transport in the engine.
