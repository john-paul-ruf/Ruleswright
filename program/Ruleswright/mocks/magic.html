Magic — pools, slots, spells as data

There is no magic subsystem. A spell is an action declaration plus magic metadata plus a cost. Memorized-slot magic and drain pools are both just pack resource policies on the same engine (FR-8, FR-9).

Two resource models, one engine

vancian — dark fantasy showcase
"slots": {
  "1": ["grave-light", null, "ward-ward"],  // bindings
  "2": [null]
}
// casting consumes a BOUND slot of the matching level;
// an empty slot cannot cast. Bindings are plain JSON
// inside the character snapshot (FR-8, FR-14).
drain pool — zombie urban showcase
"stamina": { "cap": "8 + vigor", "current": 6 }
// "adrenal-surge" costs 2 stamina — spend points,
// refill per pack policy. Same snapshot rules.

The slot lifecycle

1 · prepare

pack-declared action · gated by known-spells restriction tables (FR-9)

→
2 · bind

slot ← spell id · house rules (swap-on-rest) stay data

→
3 · cast

consume bound slot → effect DSL → events (the normal action pipeline)

→
4 · rest

host-emitted event · slots clear & pools refill per pack policy (FR-8)

Casting rides the normal action pipeline: validate → consume → resolve effect DSL → emit events. No spell-specific code anywhere.

Targeting — multi-target, per-target saves, mixed outcomes

a burst spell — complete declaration
{
  "id": "ember-bloom",
  "magic": { "level": 2, "lists": ["hexer"] },
  "cost": { "vancian": 2 },
  "targeting": { "shape": "burst", "radius": 2 },   // FR-11: single + burst in v1
  "effect": { "perTarget": {
    "save": "reason",
    "fail": "damage(3d6)",
    "pass": "damage(half)"   // save-for-half, per target
  } }
}
output
✓ burst r2 centered on grave-shambles · 3 targets
  grave-shambles  save reason 11 < 14 → fail · 9 fire
  grave-shambles  save reason 16 ≥ 14 → half · 5 fire
  brynn (ally)    save reason 13 ≥ 14 → half · 5 fire   // friendly fire is a pack choice

Restrictions are pack data

class/armor matrix + known-spells gate
"casting": {
  "armor": { "hexer": ["leather"], "warden": [] },
  "knownGate": "list.spells(level <= casterLevel/2 + 1)"  // pack policy
}
✓

CI proof 3 (FR-12): a test pack adds a new spell — it is memorized, bound, and cast with zero engine diffs.

▲

Cone and line shapes are deferred, not faked — they are engine geometry and cannot be smuggled in as data (FR-11). Single-target and burst ship in v1.
