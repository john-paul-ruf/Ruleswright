Dice & determinism

All randomness flows through one injectable, seedable, exportable RNG. Same seed and same call sequence ⇒ identical results on Node, in browsers, in Electron. There is no ambient Math.random anywhere in the library — and CI keeps it that way (FR-1).

One injection point

The engine ships a seeded default; hosts may inject their own — a rigged stream for tests, a recorded stream for replays, any distribution the host wants. Determinism is a property of the injection, not a hope.

combat.ts — API illustrative
import { mulberry32 } from "ruleswright/runtime";

const fight = rt.startCombat(
  { allies: [brynn], enemies: [rt.spawnMonster("barrow-wight")] },
  { rng: mulberry32(42) }   // or your own (seed) => number
);

A roll is structured, never a bare number

Every roll carries its purpose, its parts, and its verdict — so events (FR-13) can quote it and replays can re-render it without re-deriving anything.

roll anatomy
{
  "purpose":  "attack",
  "sides":    20,  "values": [14],
  "modifier": 3,  "total":  17,
  "verdict":  { "defense": "ac", "value": 15, "result": "hit" }
}

Recipes — the dice vocabulary formulas may use

These terms appear inside pack formulas (FR-3) and tables (FR-15). The engine evaluates them; packs combine them.

expression meaning
d20 + attackBonusthe one resolution primitive (FR-3)

1d8 + mightdamage with an ability term
d100percentile — table rolls (FR-15)

RNG state travels with the snapshot

const snap = fight.serialize();          // includes rng.state
// …process restarts, hosts reload the same pack…
const resumed = Combat.deserialize(snap, pack);
resumed.step();   // next roll == the uninterrupted fight's next roll
output
✓ rng state 0x9f3a… restored
✓ next roll d20[7] — matches the uninterrupted run (FR-14, testable)
▲

No ambient randomness: a CI lint rule fails any Math.random under src/. The rule is boring; the guarantee is total (FR-1).

◈

Cross-platform determinism: an integer-based generator, fixed rounding, no clock or locale in the roll path — same seed ⇒ same values on every engine (NFR-Determinism).
